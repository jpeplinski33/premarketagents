Listing key

Listings are encrypted, so nobody can read a property without an invite. Paste the key for the selected listing once on each device you send from. It is stored only in this browser and is never uploaded. Without it you cannot create invites or preview the listing.

Move invites to another device

Invites live in this browser only. To carry them to your phone, create a transfer link and open it there. The link is encrypted — it is useless without the one-time code, which you type on the other device. Send the link and the code separately.
