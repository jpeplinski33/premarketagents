Questions to ask before a private showing

Updated August 2026 · Educational checklist

Exclusive access can feel exciting. These questions keep the decision grounded.

About the opportunity

  • Is this home on the MLS yet? If not, when might it be?
  • Who else has been invited to preview?
  • How will offers be reviewed and timed?
  • What is included or excluded (appliances, systems, furnishings)?

About the property

  • Age of roof, HVAC, plumbing, electrical—any known issues?
  • Has there been recent work? Permits?
  • What do recent nearby sales suggest—not as a promise, as context?

About process

  • Who represents me if I want to write an offer?
  • What disclosures are available now vs later?
  • Can I revisit with specialists (inspector, contractor) if we go further?

About privacy

If you open a private digital preview, ask whether activity (time on page, photos viewed) is visible to the listing agent—and whether you’re comfortable with that. Transparent tools disclose monitoring; hidden tracking is a red flag.
